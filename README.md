Sound Identification Web App

Project Overview

Welcome to the Sound Identification Web App!

In this project, you will build a web application that listens to sounds through a computer's microphone and identifies them using a machine learning model.

When the application recognizes a sound, the animated aliens will respond.

Learning Objectives

By completing this project, you will learn how to:

Use HTML to structure a web application.

Use CSS to style a webpage.

Use JavaScript to add interactivity.

Work with a machine learning sound classification model.

Access microphone input with permission.

Display prediction results and confidence levels.

Use images and animations in a web application.

Project Features

Sound recognition using a trained machine learning model.

Microphone input.

Sound labels and prediction confidence.

Animated characters that respond to recognized sounds.

Getting Started

Open this repository.

Click Use this template to create your own copy, if enabled.

Open your copy in Visual Studio Code.

Review the HTML, CSS, and JavaScript files.

Complete the missing code sections.

Save your work.

Run the project using Live Server.

Click START and allow microphone access.

Make different sounds and observe the results.

Sounds to Test

Clap

Bell

Finger snapping

Other sounds included in the trained model

Important Notes

Allow microphone access when prompted.

Use Live Server or another localhost server to run the project.

An internet connection is required to load the external libraries and machine learning model.

Do not rename or delete the image files.
